# Advent of code - 2025 Day 1 Puzzle 1

[Source](https://adventofcode.com/2025/day/1)

Rotating dials with numbers 0-99.

Parse the input document to work out whether you spin the dial to the left or right and how far each time.
The starting point is at location `50`.

## Part 1

The answer is how many times the dial ends on `0`.
